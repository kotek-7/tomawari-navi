1. 人気スポットランキングAPI（最優先）

  - 完全別サーバーで GET /ranking?area=xxx だけ返す
  - 中身は検索履歴の件数集計だけでOK
  - フロントで「今人気の寄り道」表示すると一気にそれっぽくなる

  2. 天気連動おすすめAPI

  - GET /weather-reco?lat=..&lng=.. で「雨なら屋内スポット」返すだけ
  - ルールベース固定で十分（AI不要）
  - デモで説明しやすい

  3. スタンプラリー進捗API

  - POST /checkin, GET /progress
  - 観光遠回り結果と独立して作れる
  - ゲーム性が出てウケやすい

  4. 雑プッシュ通知サーバー

  - 条件一致でDiscord/LINEに通知送るだけ
  - 本体はイベント送信のみで疎結合

  今の状況なら、ランキングAPIが一番コスパ高いです。
  実装が最速で、フロント変更も最小、審査で「ユーザー行動を活用してる感」が出せます。
