# 追加機能案（ハッカソン向け）

## A. 粗結合（別サーバー）で追加しやすい候補

1. 人気スポットランキングAPI（最優先）
- 完全別サーバーで `GET /ranking?area=xxx` を返す
- 中身は検索履歴の件数集計だけでOK
- フロントで「今人気の寄り道」表示に使える

2. 天気連動おすすめAPI
- `GET /weather-reco?lat=..&lng=..` で「雨なら屋内スポット」などを返す
- ルールベース固定で十分（AI不要）
- デモで説明しやすい

3. スタンプラリー進捗API
- `POST /checkin`, `GET /progress`
- 観光遠回り結果と独立して作れる
- ゲーム性が出る

4. 雑プッシュ通知サーバー
- 条件一致で Discord/LINE に通知するだけ
- 本体はイベント送信のみで疎結合

## B. プロダクト軸（健康×観光の遠回り）を保った追加候補

1. 気分別遠回りモード
- 「癒やし」「映え」「静か」などで候補重みを切り替える

2. 時間予算フィット
- `15分/30分/60分` で寄り道候補を自動調整

3. 健康メリット可視化
- 「この遠回りで +何歩 / +何kcal」を表示

4. 天気・気温適応ルート
- 雨の日は屋内、猛暑日は日陰多めを優先

5. 混雑回避遠回り
- 時間帯混雑を避ける候補を優先

6. 再訪防止・未訪優先
- 履歴を見て未訪問スポットを優先提示

7. 1タップ寄り道再計算
- 移動中の現在地から即再提案

8. ごほうび導線
- 一定歩数達成で次のおすすめを解放

## C. 軸を保つ優先順（3つ）

1. 時間予算フィット
2. 健康メリット可視化
3. 再訪防止・未訪優先
